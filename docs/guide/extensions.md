# Extensions

The Kitchen Display integrates with other modules from the same author. Install the
ones you need.

| Module | Version | Description |
| --- | --- | --- |
| [`ab_pos_order_status`](https://apps.odoo.com/apps/modules/19.0/ab_pos_order_status) | 19.0 | Adds an order status screen for customers. |
| [`aks_self_order`](https://apps.odoo.com/apps/modules/19.0/aks_self_order) | 19.0 | Shows orders from the self-order menu and the current wait time. |
| [`abichinger_pos_stock`](https://apps.odoo.com/apps/modules/18.0/abichinger_pos_stock) | 18.0 | Enable or disable individual dishes from the display. |
| [`abichinger_kitchen_warning`](https://apps.odoo.com/apps/modules/18.0/abichinger_kitchen_warning) | 18.0 | Kitchen warning notifications. |
| [`ab_merge_orders`](https://apps.odoo.com/apps/modules/18.0/ab_merge_orders) | 18.0 | Merge orders. |
| [`ab_pos_self_order_checkout`](https://apps.odoo.com/apps/modules/17.0/ab_pos_self_order_checkout) | 17.0 | Self-order checkout. |
| [`ab_pos_self_order_viva`](https://apps.odoo.com/apps/modules/17.0/ab_pos_self_order_viva) | 17.0 | Viva payment for self-order. |
| [`cloud_link`](https://apps.odoo.com/apps/modules/18.0/cloud_link) | 18.0 | Cloud storage integration. |
| [`cloud_link_gdrive`](https://apps.odoo.com/apps/modules/18.0/cloud_link_gdrive) | 18.0 | Google Drive integration. |

## Features that require an extension

| Feature | Required module |
| --- | --- |
| Enable or disable individual dishes | `abichinger_pos_stock` |
| Current wait time for customers | `aks_self_order` |
| Order status screen button | `ab_pos_order_status` |

When a required module is not installed, the display shows a message with a link to
the module.
